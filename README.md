# KASHOP — Mobile App

A cross-platform mobile shopping app built with **React Native** and **Expo**.

## Tech stack

- **Expo SDK 54** with **Expo Router** (file-based navigation)
- **React Native** + **TypeScript**
- **Tamagui** for UI, React Navigation bottom tabs
- **Axios** for API communication
- Store-based state management (`src/Stores`)

## Getting started

```bash
npm install
npx expo start
```

Then open the app in an Android emulator, iOS simulator, or Expo Go. You can also run `npm run android`, `npm run ios` or `npm run web`.

## Project structure

```
src/
  app/      Expo Router screens and layouts
  Stores/   App state
assets/     Images and fonts
```
